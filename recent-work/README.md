# Recent work — WGU practice materials (2023)

Concise, self-study worksheets and reference sheets I authored as a course
instructor at **Western Governors University** (competency-based, online).
Unlike the older course archives in `teaching/`, these are recent, activity-style
materials — short targeted practice with keys — and every document includes its
editable **LaTeX source** plus the shared house style file
(`WGU_worksheet_preamble.sty`) I built for a consistent worksheet format.

| Document | What it is |
|---|---|
| [Discrete Probability Practice Problems](C960_Discrete_Probability_Practice_Problems.pdf) ([source](C960_Discrete_Probability_Practice_Problems.tex)) | Targeted practice set for C960 Discrete Mathematics II — counting, probability, expectation — with answer key. |
| [Algorithms Practice Problems](C960_Algorithms_Practice_Problems.pdf) ([source](C960_Algorithms_Practice_Problems.tex)) | Practice set on algorithm analysis for C960, with answer key. |
| [Big-O Cheat Sheet](C949_Big-O_cheat_sheet.pdf) ([source](C949_Big-O_cheat_sheet.tex)) | Two-column quick-reference on asymptotic complexity for C949 Data Structures & Algorithms, with a short self-check quiz and key. |
| [C960 Formula Sheet](C960_formula_sheet.pdf) ([source](C960_formula_sheet.tex)) | Compact formula reference for Discrete Mathematics II. |

These were written for students preparing for objective competency assessments,
so the design goal is the same as modern courseware: **short, focused,
self-contained practice with immediate feedback** — not lecture notes.
