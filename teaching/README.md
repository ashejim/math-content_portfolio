# Teaching Materials

Complete materials for nine university mathematics courses I taught at
**Johnson C. Smith University** (JCSU, 2012–2014) and **Mars Hill University**
(MHU, 2014). Everything was authored by me in LaTeX/LyX.

Each course folder follows the same layout:

```
<course>/
├── <syllabus>.pdf
├── lecture-notes/        notes and slide decks
├── assignments/          homework, quizzes, worksheets (+ worked solutions)
├── exams-and-reviews/    exams, midterms, finals, review sheets (+ solutions)
└── latex-source/         editable .tex source (advanced-algebra courses)
```

## Highlights

- **Topics in Algebra (MTH 439)** contains textbook-style lecture notes developing
  ring theory from scratch — *Rings*, *Ideals*, *Factor Rings*, and *Homomorphisms
  and Isomorphisms* — each provided as a compiled PDF and editable LaTeX source. Two
  versions of the notes are included: a full set with worked examples, and a
  "without examples" set used as in-class handouts.

- **Abstract Algebra (MTH 335)** and **Linear Algebra (MTH 336)** include complete
  homework and exam sets *with fully worked solutions*.

- The **Finite Math** and **College Algebra** courses include large banks of
  worksheets, practice exams, and review sheets suitable for adaptation into
  self-study or online content.
